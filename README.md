# Amali Akshaya — Portfolio

Personal portfolio website showcasing my work, projects, experience, and skills in **Data Science, Machine Learning, and AI**.

🌐 **Live Website:** [amali-portfolio.vercel.app](https://amali-portfolio.vercel.app/)

## Built With

* HTML
* CSS
* JavaScript
* Git & GitHub
* Vercel

## Deployment & CI/CD

* Version controlled with Git and GitHub
* Feature branches and Pull Requests used for changes
* Vercel automatically builds and deploys changes to production from `main`
* Preview deployments are generated for Pull Requests
